# C Programming & Data Structures Repository 🚀

A structured repository containing practical implementations, core concepts, and algorithmic problem-solving in **C Programming**. This repository documents my hands-on learning journey, laboratory exercises, and foundational computer science problem sets.

---

## 📌 Topics Covered

- **C Fundamentals:** Syntax, Data Types, Operators, Type Casting, and Control Flow (if-else, switch-case)
- **Loops & Patterns:** `for`, `while`, `do-while` loops, and structured number/star pattern printing
- **Functions & Scope:** Modular programming, Call by Value vs Call by Reference, and Recursion
- **Arrays & Strings:** 1D/2D Arrays, Matrix operations, String manipulation, and standard `<string.h>` library functions
- **Pointers & Memory Management:** Pointer arithmetic, Double pointers, Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, `free`)
- **Structures & Unions:** Custom data types, nested structures, and array of structures
- **File Handling:** Reading/Writing files using `fopen`, `fclose`, `fprintf`, `fscanf`, and binary file I/O
- **Basic Algorithms:** Linear Search, Binary Search, Bubble Sort, Selection Sort, and Insertion Sort

---

## 🛠️ Tools & Environment

- **Language:** C (C99 / C11 Standard)
- **Compiler:** GCC (GNU Compiler Collection) / Clang
- **Editor/IDE:** Visual Studio Code / Terminal
